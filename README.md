# articles

Source for <https://pslusarz.github.io/articles/> — a Jekyll site where I write up
things I have built or investigated.

Posts live in `_posts/`, named `YYYY-MM-DD-slug.md`. Supporting material for a post
(scans, raw tool output, data) goes in `docs/assets/<post-slug>/` so it can be linked
from the article and inspected directly.

## Local preview

```sh
bundle install
bundle exec jekyll serve
```
